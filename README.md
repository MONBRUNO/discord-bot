# Discord Bot

Discord.js 기반의 기본 봇 프로젝트입니다.

## 준비

1. Discord Developer Portal에서 애플리케이션과 봇을 생성합니다.
2. `.env.example`을 `.env`로 복사하고 값을 채웁니다.
   - 로스트아크 API 명령을 쓰려면 `LOSTARK_API_KEY`도 입력합니다.
3. 의존성을 설치합니다.

```bash
npm install
```

## 명령 등록

테스트 서버에 슬래시 명령을 등록합니다.

```bash
npm run register
```

## 실행

```bash
npm run dev
```

운영 실행은 다음 명령을 사용합니다.

```bash
npm start
```

## 현재 명령

- `/ping`: 봇 응답 속도를 확인합니다.
- `/help`: 사용 가능한 명령 목록을 보여줍니다.
- `/골드`: 입력한 골드 기준으로 4인/8인 경매 입찰가를 계산합니다.
- `/전각`: 전설 각인서 최저가 기준으로 경매 입찰가를 계산합니다.
- `/정보`: 로스트아크 캐릭터 장비, 악세서리, 각인, 보석, 카드 정보를 이미지로 조회합니다.
- `/배럭`: 계정 내 캐릭터 목록을 아이템 레벨 순으로 보여줍니다.
- `/카드`: 캐릭터 장착 카드 세트를 조회합니다.
- `/주간컨텐츠`: 이번 주 도전 어비스/가디언 정보를 조회합니다.
- `/일정`: 필드보스, 카오스게이트, 모험섬, 항해 협동 일정을 조회합니다.
